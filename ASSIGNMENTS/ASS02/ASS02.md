# Assignment 02: Network Topology

ให้นักศึกษาเปิดไฟล์ตัวอย่าง Network Topology (.pkt) ด้วยโปรแกรม Cisco Packet Tracer เพื่อสำรวจโครงสร้างเครือข่ายและบันทึกสิ่งที่สังเกตได้จากการจำลอง

## 1. สิ่งที่ต้องศึกษาและสังเกต

- Host: อุปกรณ์ปลายทางในเครือข่าย
- Network: โครงสร้างและการเชื่อมต่อของเครือข่าย
- Router: อุปกรณ์ที่ใช้เชื่อมต่อเครือข่าย
- Interface: พอร์ตหรือส่วนเชื่อมต่อของอุปกรณ์
- IP Address: หมายเลขที่อยู่ IP
- Network Mask: ค่าที่ใช้กำหนดขอบเขตเครือข่าย
- Default Gateway: เกตเวย์เริ่มต้นของอุปกรณ์

นักศึกษาสามารถบันทึกข้อสังเกตอื่น ๆ ที่เกี่ยวข้องเพิ่มเติมได้

## 2. คำถามที่ต้องตอบ

1. What is the smallest network? (เครือข่ายที่เล็กที่สุดคืออะไร?)
2. What network requires switches? (เครือข่ายลักษณะใดจำเป็นต้องใช้ Switch?)
3. What network requires routers? (เครือข่ายลักษณะใดจำเป็นต้องใช้ Router?)
